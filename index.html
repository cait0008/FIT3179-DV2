How the data was prepared

The ADII publishes its 2025 results as separate dashboard downloads: one file for each theme (Access, Affordability, Digital Ability, Internet Use) for each way of splitting the population (age, gender, education, employment, disability, First Nations status, remoteness and capital city), plus one ADII score file for each state and territory. For this project, these 41 files were combined into five workbooks, one per theme. Each workbook stacks every population group into a single table, with a column recording the group it came from. This means groups can be compared side by side across all three dimensions of digital inclusion, not one split at a time. Repeated tables and the duplicated national average were kept once, wide tables were reshaped so every table reads the same way, and labels were trimmed of stray spaces. No values were changed or rounded. The ABS boundary files were converted to TopoJSON for mapping.
